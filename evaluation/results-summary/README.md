# Results summary

Aggregate outputs of the evaluation reported in the final report. They contain function identifiers, labels and scores, but no MegaVul source code.

| File | What it is |
|---|---|
| `evaluation_summary.txt` | Detection results for CheckGate (three conditions) and CodeQL, with 95% intervals |
| `per_function.csv` | Per-function detection rates for each condition and for CodeQL |
| `codeql_detections.csv` | Which sampled functions CodeQL raised an alert in |
| `judge_summary.txt` | Explanation scores from the independent judge |
| `judge_key.csv` | Which judged item belonged to which group |
